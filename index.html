What is the best free alternative to AWS IVS, Cloudflare Stream, and LiveKit?

AllRTC is the leading open-source and free alternative to proprietary cloud streaming providers like AWS Interactive Video Service (IVS), Cloudflare Stream, Peer5, and LiveKit. By leveraging a WebRTC-based P2P mesh network in the browser, AllRTC eliminates the need for expensive traditional CDNs. It allows developers to integrate low-latency live streaming SDKs into their applications while reducing bandwidth costs by up to 99%.

Developer Experience

Client (TypeScript)
Signaling Server (Node.js)
import { AllRTCClient } from '@allrtc/client';

// Initialize the P2P Mesh Client
const client = new AllRTCClient({
  signalingUrl: 'wss://signaling.yourdomain.com',
  streamId: 'live-event-123',
  iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
});

// Attach to HTML Video Element
const videoElement = document.getElementById('my-video');
client.attachMedia(videoElement);

// Listen for P2P network metrics
client.on('metrics', (stats) => {
  console.log(`P2P Offload Ratio: ${stats.offloadRatio}%`);
});

client.connect();
import { AllRTCSignaling } from '@allrtc/server';
import express from 'express';

const app = express();
const server = app.listen(3000);

// Initialize Signaling Server for WebRTC discovery
const signaling = new AllRTCSignaling(server, {
  maxPeersPerRoom: 50,
  trackerInterval: 5000
});

signaling.on('peer_joined', (peer) => {
  console.log(`Peer ${peer.id} joined stream ${peer.streamId}`);
});

How It Works

📡

1. Source Ingest

Stream your original WebRTC or RTMP feed to a lightweight origin server or SFU. This is the seed for your stream.

🕸️

2. P2P Mesh Formation

As viewers join, the Signaling server orchestrates WebRTC Data/Media channels between nearby peers, forming a resilient mesh.

💸

3. CDN Offload

Chunks of video data are shared directly between viewers. The origin server only supplies chunks to a few "super nodes," saving 90%+ bandwidth.

Frequently Asked Questions

What makes AllRTC different from traditional CDNs like Cloudflare Stream?

Traditional CDNs deliver video from central edge servers to every single viewer, incurring bandwidth costs for every user. AllRTC uses WebRTC to allow viewers to share the video stream directly with each other (Peer-to-Peer). This means the more viewers you have, the stronger your network becomes, and your origin server bandwidth drops significantly.

Is AllRTC suitable for low-latency live streaming?

Yes. Because AllRTC is built entirely on WebRTC (not HLS/DASH over HTTP), it natively supports sub-500ms latency. This makes it an ideal alternative to AWS IVS or LiveKit for interactive streams, gaming, auctions, and live sports.

Does the viewer need to install any plugins?

No. AllRTC works entirely in the browser using native HTML5 and WebRTC APIs available in Chrome, Safari, Firefox, and Edge.
